# M5 Project CharcoESP

## Overview
The M5 Project CharcoESP aims to create an innovative solution for monitoring and managing environmental conditions through an integrated system utilizing the M5Stack ESP32 device. This project focuses on providing real-time data collection and analysis for various environmental parameters.

## Features
- **Real-time Data Monitoring**: Capture and display environmental data instantly.
- **User-friendly Interface**: Designed with usability in mind for easier interaction and accessibility.
- **Data Logging**: Save historical data for future analysis.
- **Alerts and Notifications**: Receive alerts based on predefined thresholds for environmental conditions.

## Components Used
- **M5Stack ESP32**: The core processing unit of the project.
- **Sensors**: Various sensors are used for monitoring different environmental parameters (e.g., temperature, humidity, air quality).
- **Power Supply**: Suitable power management to ensure reliability and efficiency.

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/BetuelRS/M5_Project_CharcoESP_BetuelSouza.git
   ```
2. Set up the M5Stack ESP32 environment.
3. Follow the instructions in the documentation to configure the sensors.
